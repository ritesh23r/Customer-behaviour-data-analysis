# Customer Shopping Behaviour Analysis

This project analyzes customer shopping behaviour using a retail dataset to help businesses understand how customers spend, what they buy, and what factors influence their purchasing decisions.

The analysis is done using three tools — **Python** for exploratory data analysis, **SQL** for answering specific business questions, and **Power BI** for building an interactive dashboard.

---

## What This Project Covers

- Revenue breakdown by gender and age group
- Whether subscribed customers spend more than non-subscribers
- Which products have the highest ratings and sales
- How discounts influence spending behaviour
- Customer segmentation into New, Returning, and Loyal buyers
- Comparison of Standard vs Express shipping on purchase value
